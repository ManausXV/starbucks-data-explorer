Three things worth knowing
The store directory is older than the store count

The searchable directory holds 28,289 stores from a 2017 dataset, while the FY2025 filing reports 40,990 stores. Both numbers are correct for their own date, and the directory simply predates roughly 12,700 newer stores. The site shows both rather than quietly picking one.

The cost bars do not add up to exactly 100%

The Financials cost breakdown shows the five expense lines reported for each segment, plus operating income. A few smaller items, including other operating expenses and income from partner businesses, sit outside those lines, so each bar comes close to the segment's full revenue without matching it exactly.

Rewards numbers are US-only and unevenly spaced

Members are counted as 90 day active users in the United States, so this is not a worldwide total. One reading is dated only as "about 2022" in the source. It is kept, shown in grey, and never used to calculate a growth rate.

How this site was built

One JSON file and three CSV files are loaded into ten database tables by a single command, which can be re-run at any time to rebuild the data from scratch. Every page queries those tables directly, so no figure on this site is typed into a template by hand.

Filtering happens in two different places, on purpose. The store directory searches 28,289 rows on the server and returns fifty matches at a time, because sending every row to the browser would be wasteful. The menu holds only 355 items, so the whole menu is sent once and filtered instantly in the browser with no further requests.
