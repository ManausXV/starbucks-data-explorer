Three things worth knowing
The store directory is older than the store count

The searchable directory has 28,289 stores in it, from a dataset put together in 2017. The FY2025 annual report says there are 40,990 stores. Both are right for their own moment in time. The directory just predates about 12,700 newer shops. I'd rather show both numbers and explain the gap than quietly pick whichever one looks better.

The cost bars don't quite add up

On the Financials page, each bar breaks a segment's revenue into the five cost lines Starbucks actually reports, plus whatever profit is left. A few smaller things sit outside those five, like other operating costs and income from partner businesses. So the bars land close to full revenue without matching it exactly.

The Rewards numbers are patchy

They count people in the US who used Rewards in the last 90 days, so this isn't a worldwide membership total. The readings also aren't evenly spaced, which is why they're bars rather than a line. One of them is dated only as "about 2022" in the source. I kept it, coloured it grey, and never use it to work out growth.

How this site was built

One JSON file and three CSVs get loaded into ten database tables by a single command, which I can run again at any point to rebuild everything from the original files. Every page reads from those tables, so nothing you see here is a number I typed into a page by hand.

Searching works differently in two places, deliberately. The store directory has 28,289 rows, which is far too many to hand to a browser, so the server does the searching and sends back fifty matches at a time. The menu is only 355 items, so the whole thing goes to the browser once and filtering happens instantly, without asking the server again.
